            Log too big? Split it first, then select all the parts
            
Maximum 50 MB per file, plain text (.log, .txt) or gzip (.gz; the limit applies to the compressed size). Only the statistics are kept on the server, never the raw log. Run these on the machine that has the log:

            

              
Last 200,000 lines (the most recent traffic)tail -n 200000 haproxy.log > haproxy-part.log

              
First 200,000 lineshead -n 200000 haproxy.log > haproxy-part.log

              
Cut into ~40 MB pieces without breaking a line (haproxy-part-00, -01, …)split -C 40M -d --additional-suffix=.log haproxy.log haproxy-part-

              
Cut into pieces of 200,000 linessplit -l 200000 -d --additional-suffix=.log haproxy.log haproxy-part-

              
Keep one day and hour (syslog format “Nov 10 08:…”)grep -E '^Nov 10 08:' haproxy.log > haproxy-8am.log

              
Only one frontend, or only errorsgrep ' famsapp~ ' haproxy.log > part.log grep -E '" (5[0-9][0-9]) ' haproxy.log

              
Compress a part (logs shrink about 10×)gzip -k haproxy-part.log

              
Check the size before uploadingls -lh haproxy-part*
